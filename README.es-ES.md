# atheos
AtheOS es un nuevo sistema operativo desarrollado por Kurt Skauen bajo la licencia GPL. No cuenta con un modo texto real, pero es posible utilizar emuladores de terminal. Hasta la fecha está disponible únicamente para procesadores x86, y se admiten SMP y multihilo. Además de sus características UNIX, soporta POSIX en gran medida y se basa en una nueva interfaz de usuario y en un sistema de archivos rediseñado. El sistema de archivos AFS de 64 bits cuenta con funciones de journaling. El kernel monolítico fue diseñado de forma modular. Se han portado aplicaciones relacionadas con UNIX como bash y herramientas CLI, y el propio AtheOS está programado en C++. Gracias al soporte TCP/IP, está destinado tanto a sistemas de escritorio como a servidores web. 

Mientras tanto, todo apunta al cierre del proyecto AtheOS, aunque quizás en el futuro se siga desarrollando. Después de todo, han pasado varios años desde la última versión.
